Lock Report as v1.0
×

Locking this report will:

  • Immutably store version v1.0 with the current content and metadata
  • Generate a signed audit trail record
  • Unlock Download Excel, Share, and Audit Trail actions
  • Add this version to the report's version history

Future modifications will create new versions (v2.0, v3.0). The locked v1.0 remains accessible.

🔒 Admin Lock — Permanent Freeze
×

Admin Lock is irreversible. Once applied:

  • No new versions can be created on this report — the New Version button will be disabled
  • The version cannot be edited via Modify with Ra
  • The report cannot be deleted from Issued Reports
  • An additional admin-lock entry is appended to the audit trail with your user ID and timestamp

Use Admin Lock only when the report has been formally issued to regulators, external auditors, or legal counsel — and any later changes must take the form of a separately-issued supplementary report rather than an amendment.
